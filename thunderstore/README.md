# Stonewards FOVPlus

**Increase Stonewards' field of view up to 150° using the original in-game slider.** No extra UI or hotkeys — just a wider view.

## ✨ Features

- **Wider FOV** — extend the game's original **100° maximum to 150°**.
- **Native settings** — keep using the built-in **Settings → Game → FOV** slider.
- **No new controls** — no additional menu, keybinds, or settings file to manage.
- **Client-side** — other players do not need to install FOVPlus.

## 🎮 How to use

Launch the game with FOVPlus, open **Settings → Game → FOV**, and move the normal slider to your preferred value (up to **150°**). The game continues to handle the camera and save your setting normally.

**Before uninstalling, set FOV back to 100° or less** so your saved value stays within the unmodded range.

## 📦 Installation

Install **FOVPlus** with **r2modman** or another compatible Thunderstore mod manager, then launch Stonewards using **Start modded**. The required BepInExPack dependency is installed by the mod manager.

If you have an old **FOVControl** development build installed, remove or disable it to avoid duplicate FOV patches.

## 🔧 Compatibility

- **Game:** Stonewards **0.2.3**.
- **Mod loader:** BepInEx 5.
- **Multiplayer:** Client-side; the host and teammates do not need the mod.

## ⚠️ Known limitations

Return your FOV to **100° or below before uninstalling**. Future game updates that change the built-in FOV settings method may require a mod update.
